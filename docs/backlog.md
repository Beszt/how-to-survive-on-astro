# Backlog (luźne pomysły)

> Miejsce na pomysły, które jeszcze nie pasują do żadnego Etapu. Tu nic nie ginie — wszystko, co warto zapamiętać, ląduje tutaj.
> Później sortujemy: → do Etapu (zobacz [milestones.md](milestones.md)) albo → do kosza.

## Pomysły gameplayowe

- [ ] **Odroszczacz** (dew heater), który trzeba pamiętać włączyć — inaczej zamglone zdjęcia
- [ ] samochód, który nie chce odpalić na mrozie (humor)
- [ ] bateria, która umiera dokładnie w najgorszym momencie
- [ ] „termos z kawą" — im dłużej fotografujesz, tym bardziej go potrzebujesz
- [ ] sąsiad z lampą, która zaśmieca Twoje niebo (gag)
- [ ] „star party" — event z lokalnym stowarzyszeniem
- [ ] sprzedaż wydruków zdjęć mieszkańcom
- [ ] „dark sky tour" — gracz prowadzi wycieczki (późniejszy przychód)
- [ ] rywal-astrofotograf (lekki antagonista)
- [ ] „rozbłysk meteorów" — rzadki, limitowany czasowo event
- [ ] fotografowanie ISS / Księżyca

- [ ] „dziennik sprzętowy" — historia zakupów i awarii
